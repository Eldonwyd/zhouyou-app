INSTALL TIPS & FAQ

安装贴士与常见问题

为什么网页在线漫游版不能使用 AI 规划和保存照片？

官网内置的「网页漫游沙盒」专为免安装快速预览打造，开放全国 370+ 城市地图点亮、皮肤切换与示例路书/手账浏览；下载电脑或手机客户端，或打开完整版 PWA 并登录周游账号，即可解锁多模型 AI 规划、三端云同步、同行旅伴好友协作以及完整原图照片存储。

macOS 首次打开提示「已损坏」或「无法验证开发者」怎么办？

作为免费开源软件，暂未购买苹果年费公证证书。将应用拖入「应用程序」文件夹后，在终端执行下方命令解除隔离属性即可正常打开：

xattr -cr "/Applications/Zhouyou Map.app"
Windows 弹出 SmartScreen 蓝色保护提示怎么办？

开源独立安装包未购买昂贵的 EV 代码签名证书，首次安装可能出现 Windows Defender SmartScreen 提示。点击弹窗左侧的 「更多信息」 → 再点击 「仍要运行」 即可安全安装，全部源码均在 GitHub 公开可审计。

Linux 如何运行 AppImage 或安装 .deb 包？

AppImage 通用包赋予执行权限后直接运行，或 Debian/Ubuntu 使用 apt 安装：

chmod +x Zhouyou-Map-*.AppImage && ./Zhouyou-Map-*.AppImage
sudo apt install ./Zhouyou-Map-*.deb
手机端怎么选 APK 还是 PWA？

安卓手机推荐优先安装 .apk 独立客户端（支持免电脑直登 ChatGPT / Claude / Kimi 订阅）；追求轻快免安装或使用 iPhone 时，可将 PWA 网页版添加到主屏幕（打开快、自动更新，但 AI 订阅登录受浏览器限制，建议搭配 API Key 使用）。

如需在手机上使用 AI 规划，可在电脑桌面版顶部菜单开启「允许局域网手机连接 AI 服务」，然后在手机端「个人中心 → 设置 → 远程 / 局域网 AI 服务」填入局域网地址即可无线互联。
