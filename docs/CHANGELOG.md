# 更新日志 · Changelog

本项目版本号遵循 [Semantic Versioning](https://semver.org/) 规范。

## [1.0.0] - 2026-11-23

### ✨ 新增功能
- **全平台原生客户端支持**：
  - 电脑桌面端（Electron）：支持 **Windows (`.exe` 安装版 & 绿色便携版)**、**macOS (Apple Silicon `arm64` & Intel `x64` `.dmg`)**、**Linux (`.AppImage` & `.deb`)**，内置完整 Node.js AI 服务与本地 OCR，无需安装 Node.js 开箱即用。
  - 手机移动端（Capacitor + PWA）：支持 **Android (`.apk`)**、**iOS (`.ipa` 自签安装包)** 以及 **Safari / Chrome PWA 一键添加到主屏幕**。
  - 支持桌面端一键开启**局域网手机共享**，手机 App 填写电脑局域网地址即可互联调用 AI 行程规划。
- **GitHub Actions 自动化发布流水线**：推送 `v*.*.*` 标签自动并行构建五大平台安装包并生成校验文件发布到 GitHub Releases；同步部署在线网页版与智能设备识别下载中心到 GitHub Pages。
- **核心应用功能**：
  - 🗺️ **中国足迹地图**：内置全国 34 个省级行政区与地级市边界、碰撞避让标签、点亮“已去过/计划前往”、离线地图包缓存。
  - 📔 **旅行手账与媒体库**：城市明信片封面、按行程/地点整理文字笔记、照片/视频/语音录制、GPS 城市校验。
  - 🤖 **多模型 AI 行程规划**：支持 DeepSeek / OpenAI / Claude / Gemini / 通义千问 / 智谱 / Kimi 及主流订阅账号登录，支持联网检索、交互式路线地图、接驳方案对比、景点门票预约提醒、AI 行李清单、截图 OCR 导入票据与离线路书 HTML 导出。
  - 💰 **每日账本与 AA 分账**：支持三餐/交通/门票/住宿/其他逐日记账与整数分精确 AA 结算。
  - 🏆 **旅途成就与分享海报**：八大旅人成长里程碑、徽章解锁与一键导出成就海报。
  - 🎨 **五套主题皮肤与深浅色模式**：糖果贴纸、纯白极简、纸感手账、海风海岸、暖日手账，支持浅色 / 深色 / 跟随系统。
  - 📦 **本地隐私优先**：所有数据本地 IndexedDB 存储，支持 ZIP v3 跨设备完整导出与恢复。
